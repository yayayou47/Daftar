DAFTAR — SUIVI FINANCIER, ENGINS ET MAISON
==========================================

Daftar note vos dépenses, revenus, comptes (espèces, banques, mobile
money), prêts aux proches, biens et patrimoine, ainsi que le carnet de vos
engins (carburant, kilomètres, vidanges) et de votre maison (travaux). Tout
est en francs CFA, en français, et fonctionne sans internet. Vos données
restent chez vous.

Ce mode d'emploi a trois parties :
  I.   PREMIERS PAS : installer, découvrir, première saisie.
  II.  USAGE QUOTIDIEN : noter, lire ses chiffres, corriger.
  III. AVANCÉ : comptes de tiers, relevés, téléphone synchronisé, commande
       daftar, sauvegardes, changer d'ordinateur.

Le numéro de version s'affiche en bas de chaque page.


######################################################################
I. PREMIERS PAS
######################################################################

1. TROIS FAÇONS D'UTILISER DAFTAR
---------------------------------
Les trois versions viennent du même code (https://github.com/yayayou47/Daftar,
publié sans aucune donnée).

  - Lien web, le plus simple : https://yayayou47.github.io/Daftar/ dans
    Chrome, puis ⋮ › « Installer l'application ». Mise à jour automatique.
    Les données restent dans l'appareil.
  - Android : fichier Daftar-<version>.apk de la page « Releases » du dépôt
    (autoriser l'installation depuis cette source la première fois). Les
    données restent dans le téléphone.
  - Ordinateur Ubuntu : fichier Daftar-ubuntu-<version>.zip de la page
    « Releases ». Les données sont dans ~/Daftar/donnees/carnet.json, avec
    une copie de sécurité chaque jour. L'ordinateur peut aussi servir un
    téléphone synchronisé (partie III, chapitre 13).

Sur le téléphone (lien web ou APK), les données n'existent QUE dans
l'appareil : exportez-les régulièrement (chapitre 10). Daftar vous le
rappelle par un bandeau quand votre dernière sauvegarde a plus de 7 jours et
que vous avez saisi quelque chose depuis.


2. INSTALLER SUR UBUNTU
-----------------------
Prérequis : Ubuntu 20.04 ou plus récent (Python 3 est déjà installé). Aucun
droit administrateur (sudo) n'est nécessaire.

Dans un terminal (Ctrl+Alt+T), placez-vous dans le dossier décompressé, où
qu'il soit (Téléchargements, disque externe, clé USB…), puis :

    bash installer.sh

Utilisez « bash installer.sh » et non « ./installer.sh » : sur un disque
externe NTFS ou exFAT, Ubuntu refuse d'exécuter les fichiers directement
(« Permission non accordée ») ; avec « bash », ce droit n'est pas nécessaire.

L'installation copie Daftar dans ~/Daftar, le fait démarrer à chaque
ouverture de session, ajoute « Daftar » au menu des applications et une icône
sur le bureau (clic droit › « Autoriser le lancement » la première fois),
installe la commande daftar et ouvre Daftar dans le navigateur
(http://localhost:8780). Le dossier d'où vous l'avez lancée devient la COPIE
MIROIR de vos données (chapitre 14).

Variantes :
    bash installer.sh --ici            garder Daftar et ses données dans ce dossier
    bash installer.sh --sans-service   pas de démarrage automatique
    bash installer.sh --reseau         accès depuis un téléphone du même Wi-Fi (chapitre 13)

Mettre à jour : décompressez la nouvelle version et relancez
« bash installer.sh ». Vos données ne sont jamais écrasées. Rechargez ensuite
l'onglet Daftar déjà ouvert (F5) : la mise à jour n'en ouvre pas un nouveau.


3. PREMIER LANCEMENT ET DÉMO
----------------------------
Avec un carnet vide, une page d'accueil présente Daftar et les trois
premières étapes : vos comptes, vos engins et votre maison, votre première
opération.

La DÉMO (bouton « Démo » en bas de page, ou adresse terminée par « ?demo »)
montre trois années de données simulées : comptes, salaire, dépenses,
voiture, moto, groupe électrogène, construction d'une villa, mariage,
mission, baptême, prêts, frais bancaires. Elles sont rangées à part : vos
propres données ne sont ni lues ni modifiées. « Recréer les données de
démo » les remet à zéro ; « Quitter la démo » ramène à votre carnet. C'est la
seule façon d'en sortir : le bouton « précédent » laisse dans la démo.


4. LES RUBRIQUES
----------------
La ligne du haut porte le logo Daftar (le toucher ramène à l'accueil : Mes
finances, vue Mois, mois en cours), l'état de la synchronisation, la devise,
le bouton jour / nuit (☀ / ☾) et le menu ≡ (Données et réglages). Par
défaut, Daftar suit le mode clair ou sombre du navigateur ; le bouton choisit
l'autre, et le choix est retenu sur l'appareil. Rebasculer vers le mode du
navigateur revient au réglage automatique. Elle reste figée en haut
de l'écran pendant le défilement.

La barre des rubriques est en bas de l'écran sur le téléphone, où elle
s'efface pendant qu'on fait défiler la page et revient dès qu'on s'arrête ;
sur l'ordinateur, elle est figée juste sous la ligne du haut :

  - Mes finances (à gauche) : vues Mois, Année, Patrimoine et
    Statistiques, avec le journal de toutes les opérations.
  - Saisir (au milieu, gros bouton bleu cerclé d'or sur le téléphone) : la carte de saisie d'une opération, le
    curseur dans le champ Montant.
  - Mes biens (à droite) : la liste des biens (engins, maisons, autres
    biens). Toucher un bien l'ouvre : Engins (vidanges, carburant,
    consommation, coûts de chaque engin), Maison (terrain, construction,
    travaux, projet), ou Patrimoine pour un autre bien. « Modifier les
    biens » ouvre Comptes et biens ; « + Ajouter un engin » et « + Ajouter
    un bien » en créent. La barre Tous | Engins | Maison passe de l'un à
    l'autre.
  - Données et réglages (menu ≡ en haut à droite) : une liste, chaque
    réglage avec une courte description, en quatre groupes :
      Saisir : Une opération · Coller une liste · Relevé bancaire ;
      Personnaliser : Postes et libellés · Comptes et biens · Événements et
        revenus · Programmées · Repères vidange · Projet maison · Saisie ·
        Parités ;
      Sécurité : Sauvegarde et retour ;
      Fichiers : Exporter vers Excel.
    Toucher un réglage l'ouvre seul ; « ‹ Réglages » (ou le bouton retour)
    ramène à la liste. « Comment ça marche ? » ouvre les explications. Un
    point orange sur un onglet et un bouton « Enregistrer » encadré signalent
    des modifications non enregistrées ; fermer la page demande alors
    confirmation.

Toucher une rubrique l'ouvre en haut de la page ; toucher un onglet amène
directement à son contenu. Le bouton retour du téléphone ramène à la
rubrique, à la vue ou à l'onglet précédents (et ferme d'abord une fenêtre
ouverte) ; seul le premier écran fait sortir de Daftar. Laissé ouvert d'un
jour à l'autre, Daftar passe de lui-même au nouveau jour.

En bas de page : « © Licence » (licence MIT et composants inclus),
« À propos » (où sont vos données, liens du code et de la version web) et
« Démo ».

II. USAGE QUOTIDIEN

5. UNE NOTE POUR CHAQUE OPÉRATION
---------------------------------
Chaque ligne est une opération. Sa NATURE se lit dans le libellé, sans
signe + ou − ; Daftar affiche ce qu'il a reconnu (nature, poste, compte,
type de revenu, événement, engin) puis un résumé à confirmer.

    10000 vivres                     dépense, payée en espèces
    200000 salaire banque            revenu sur le compte Banque
    5000 intérêts épargne            revenu sur le compte Épargne
    5000 intérêts                    revenu sur le compte épargne qui porte un taux
    80000 retrait banque             virement Banque → Espèces (pas une dépense)
    100000 épargne banque > mobile   virement entre deux comptes
    4000 abonnement carte            dépense payée avec le compte « carte »
    prêt 100000 Ali                  prêt accordé : ouvre sa créance
    remb 75000 Ali                   remboursement reçu : réduit sa créance
    50000 ciment maison              investissement dans le bien « maison »
    25000 carburant 35,7L 110882km   dépense du véhicule : 35,7 litres, compteur
    17000 vidange huile 110818km     entretien ; met à jour le repère de vidange
    12000 pharmacie                  dépense payée en espèces

Compte qui paie : sans précision, la dépense est faite en espèces. Un
mot-clé d'un compte (« banque », « mobile »…) présent dans la ligne désigne
ce compte (comptes et mots-clés : chapitre 11).

Un retrait n'est jamais une dépense : les dépenses faites avec l'argent
retiré sont notées une à une. Un prêt sort de votre argent comme une
dépense, mais la personne garde un compte de ce qu'elle vous doit jusqu'à ce
qu'il revienne à zéro ; « Adam » retrouve « Adam Issa » s'il est le seul de
ce nom. Les frais de construction et d'entretien d'un bien sont des
investissements : ils sortent de vos comptes, s'ajoutent au coût du bien et
ne comptent pas dans les dépenses courantes du mois.

Montants : ils se tapent en francs CFA (10000 = 10 000 CFA). Pour aller plus
vite, Données et réglages › Saisie › « Taper les montants en milliers »
(réglage propre à chaque appareil) : 10 = 10 000, 2,5 = 2 500,
1750 = 1 750 000 ; un nombre de 10 000 ou plus, ou écrit avec ses milliers
séparés (« 5 000 »), est alors pris tel quel. Sous le champ, Daftar affiche
le montant compris. Un « − » devant le montant veut dire « sortie »
(dépense) ; le montant enregistré reste positif. Un solde noté peut être
négatif (découvert).

Clavier Daftar (téléphone) : toucher un champ de montant ouvre un clavier
propre à l'application (1 2 3 en haut, virgule, −, « 00 », « 000 »).
« ⌨ Clavier du téléphone » revient au clavier habituel pour ce champ ;
« OK » ferme. À couper dans Données et réglages › Saisie.

Coller une liste (Données et réglages) : une ligne par opération, au format
« montant libellé [le JJ/MM/AA] » ; la date d'une ligne vaut pour les
suivantes, un nom de mois en fin de ligne et les cumuls entre parenthèses
sont ignorés. Vérifiez nature, compte et poste dans l'aperçu (une case par
ligne permet d'en écarter une), puis importez.


6. ENGINS
---------
Dans Comptes et biens, chaque bien a un « Rôle » : bien simple, Engin
(voiture, moto, bus, camion, groupe électrogène, autre) ou Maison. Le bouton
« + engin » de Mes biens › Engins (ou « + Ajouter un engin » de Mes biens)
en ajoute un. Un groupe électrogène se suit
en HEURES de marche (vidange tous les 250 h par défaut, consommation en
L/h) ; les autres engins en kilomètres. Avec plusieurs engins, une barre
passe de l'un à l'autre.

Une note est une dépense d'engin si elle cite l'engin par son nom
(« réparation corolla »), si elle contient un mot propre aux engins
(carburant, essence, gasoil, vidange, garage, pneu, ou une pièce : filtre,
boîte, radiateur, démarreur, injecteur, bobine, frein, embrayage,
suspension, diagnostic…), ou si elle tombe dans un poste réservé aux engins
(comme « Voiture », dont les mots-clés contiennent carburant, vidange,
garage…). Ces mots passent avant l'ordre des postes et avant les mots-clés
des biens : « filtre huile boîte » va à la voiture et non au Foyer,
« réparation pompe boîte » à la voiture et non à la pompe du terrain.

Quel engin ? Celui que la note nomme, ou dont elle cite le type s'il est le
seul de ce type (« essence moto » → la moto) ; sinon l'engin d'un poste
réservé aux engins, sinon l'engin affiché. Le type seul ne suffit pas à
faire une dépense d'engin : « taxi moto » reste un transport payé.

Un poste partagé avec un engin (Foyer pour un groupe électrogène, Transport
pour une moto) garde ses dépenses ordinaires hors de l'engin : « riz » ou
« taxi » ne sont pas des frais d'engin. Dans Une opération, le choix
« Engin » propose alors « — aucun engin — ». Une note trop vague
(« réparation vitre ») ne désigne aucun engin : choisissez le poste dans le
formulaire, ou ajoutez le mot aux mots-clés du poste.

Litres et compteur : « 35,7L » et « 110882km » se lisent sur les lignes d'un
engin. L'ancienne forme « 25 essence (35,71) (106183) » reste comprise
(nombre décimal = litres, nombre de 10 000 ou plus = compteur) sur une ligne
d'engin ; ailleurs, un nombre entre parenthèses est un cumul ignoré. Seul un
compteur écrit avec « km » désigne un engin à lui seul.

Vidange : en cochant « Nouvelle vidange » dans Une opération, la prochaine
est proposée au compteur + l'intervalle (modifiable) ; dans Repères vidange,
la prochaine se recalcule quand on change la dernière ou l'intervalle.

La rubrique Engins montre la barre d'avancement vers la prochaine vidange,
les dépenses (comparées à l'année précédente à la même date, en vert si
elles baissent, en rouge si elles montent), le carburant, l'entretien et les
réparations, le prix moyen du litre, la consommation (en couleur si elle
s'écarte de plus de 10 % de la moyenne de l'engin), la date estimée de la
prochaine vidange (au rythme des 6 derniers mois), les km parcourus, le coût
par km, un récapitulatif mensuel ou annuel, les vidanges et le journal de
l'engin.


7. LIRE SES CHIFFRES : MES FINANCES
-----------------------------------
Vue Mois, dans cet ordre : dépenses courantes et entrées courantes côte à
côte, solde du mois, comparaison avec la même période du mois précédent,
taux d'épargne, investi et prêté, plus grosse journée, jours sans dépense,
moyenne par jour et médiane, exceptionnel, puis les dépenses par semaine,
la répartition par poste et le journal.
  - La médiane dit ce qu'est un jour ordinaire : un jour sur deux, on
    dépense moins qu'elle ; contrairement à la moyenne, quelques grosses
    journées ne la tirent pas vers le haut.
  - Taux d'épargne = (revenus courants − dépenses courantes) / revenus
    courants ; les remboursements et les revenus ponctuels ne comptent pas.
    Pour le mois en cours s'ajoute le taux PRÉVISIONNEL de fin de mois (en
    jaune) : revenus courants attendus moins dépenses prévues (à ce jour +
    moyenne par jour × jours restants). Revenu attendu : chaque revenu
    courant reçu chacun des 3 mois précédents, au montant du mois dernier ;
    sans revenu fixe, la moyenne des 12 derniers mois. Le taux réel reste
    « — » tant que les revenus habituels ne sont pas arrivés.
  - Le journal colore l'en-tête de chaque jour selon ses dépenses
    courantes : on partage l'écart entre la journée la moins chère et la
    plus chère en trois tranches égales, vert (bas), jaune (milieu), rouge
    (haut). Les virements ne comptent pas.

Vue Année : même présentation, comparaison avec l'année précédente à la
même date, moyenne mensuelle, mois le plus cher, dépenses par mois et un
tableau mois × poste.

Vue Patrimoine : patrimoine net = comptes + biens + ce qu'on vous doit, avec
sa répartition, le disponible et l'épargne, les intérêts attendus sur un an,
les mois d'autonomie (combien de mois vos comptes tiendraient sans revenu)
et le « non saisi » (écarts de vos soldes notés).
  - Compte : solde = dernier solde noté (« Noter le solde ») + opérations
    postérieures. Chaque solde noté est comparé au précédent : un écart
    signale une opération oubliée.
  - Bien : prix d'achat + investissements = coût de revient ; notez sa
    valeur actuelle (« Mettre à jour la valeur ») pour voir la plus- ou
    moins-value et le taux annuel moyen.
  - Prêts : prêté, remboursé, reste dû, échéance (en rouge si dépassée).
  - Montants masqués : dans cette vue seulement, les montants s'affichent
    « ••••• » à chaque ouverture et quand l'application passe en
    arrière-plan. « 👁 Afficher » dans la carte du patrimoine net les montre.

Statistiques, par mois, par année, sur une période choisie ou sur tout
l'historique : alertes (prêt en retard, rythme de dépense, écarts des soldes
notés dans la période, avec les sorties et les entrées non notées à part…), bilan de la période, cumuls avec projection et comparaison à la
période précédente, dépenses par jour et par jour de la semaine, libellés
les plus coûteux, composition du patrimoine, puis conclusions et
perspectives. Chaque graphique a un « Voir les données ».

Début du suivi : si une date de début du suivi quotidien est réglée, les
indicateurs des vues Mois, Année et Statistiques ne comptent que les jours
suivis ; le journal montre toujours tout.

Montants abrégés : dans les cartes d'indicateurs, 355 K (milliers), 1,28 M
(millions). Le montant exact apparaît en survolant le chiffre, et les
lecteurs d'écran le lisent en entier. Pour tout afficher en entier :
Données et réglages › Saisie › « Montants abrégés dans les cartes ».

Filtrer : touchez un poste, un compte, une personne, un bien, un mois ou une
année pour filtrer le journal ; Daftar y amène directement.


8. HOUSE (MAISON)
-----------------
Coût de revient (terrain + travaux), valeur actuelle et appréciation,
travaux par année ou par mois et par catégorie (arrosage, eau-pompe-forage,
maçonnerie, matériaux, main-d'œuvre, électricité, administratif…),
perspectives (budget du projet, reste à investir, date d'achèvement au
rythme actuel, effort mensuel pour tenir l'échéance, valeur projetée) et
journal des travaux. Le projet se règle dans Données et réglages › Projet
maison.


9. CORRIGER, ANNULER, EXPORTER
------------------------------
Toucher une ligne d'un journal l'ouvre dans « Une opération » ; après
« Enregistrer » ou « Annuler », on revient là où l'on était. ✕ puis
« Supprimer ? » efface une ligne.

Supprimer une opération, retirer un compte, un bien, un événement, un type
de revenu, une opération programmée ou une devise, ou enregistrer un
réglage, affiche « Annuler » pendant 10 secondes en bas de l'écran.
Données et réglages › Sauvegarde et retour › Retour en arrière garde les 20
derniers changements de réglages ; « Rétablir l'état d'avant » y revient (les
lignes déplacées retrouvent leur poste). « Revenir aux réglages d'origine »
remet postes, budgets, types de revenus et parités comme à l'installation,
sans toucher aux opérations ni aux comptes ; ce retour s'annule aussi.

Exporter (menu ≡ › Fichiers › Exporter vers Excel) : Tout, Mes finances,
Engins ou Maison.
Montants en francs CFA ; le fichier Daftar_<rubrique>_<date>.xlsx s'ouvre
avec LibreOffice Calc.

Devise d'affichage : le menu en haut (FCFA, €, $, ¥…) convertit les montants
affichés ; l'onglet « Parités » règle les taux. La saisie et l'export
restent en francs CFA.


10. SAUVEGARDER (TÉLÉPHONE)
---------------------------
Données et réglages › Sauvegarde : « Exporter mes données » crée un fichier
appya-AAAA-MM-JJ.json, à garder en lieu sûr (Drive, ordinateur, envoi à
vous-même) ; « Importer » le recharge, sur le même appareil ou un autre. Ce
fichier a le format de donnees/carnet.json de l'ordinateur.

Rappel : si vous avez saisi quelque chose depuis votre dernier export et que
celui-ci date d'au moins 7 jours (ou si vous n'avez jamais exporté), un
bandeau « Pensez à sauvegarder vos données » propose « Exporter
maintenant » ou « Dans 3 jours ». Pas de rappel dans la démo ni sur
l'ordinateur, qui garde déjà une copie chaque jour.

III. AVANCÉ

11. COMPTES, POSTES ET MOTS-CLÉS
--------------------------------
Données et réglages › Comptes et biens présente « Mes comptes » et
« Comptes de tiers ». Un compte a un type (espèces, courant, épargne, carte,
mobile money, tiers), une couleur, des mots-clés et, pour une épargne, un
taux d'intérêt. Un bien a une date et un prix d'achat, des mots-clés
d'investissement et le poste de ses frais d'usage.

Supprimer un compte : ✕ (à toucher deux fois), même s'il a des opérations
(sauf Espèces). Il passe dans « Comptes supprimés », masqué partout avec ses
opérations, et « Rétablir » le ramène tel quel pendant 30 jours. Passé ce
délai, le compte et ses opérations sont effacés pour de bon.

Postes (onglet « Postes et libellés ») : ajouter, renommer, recolorer,
supprimer un poste (ses lignes vont dans le poste de votre choix) ; budget
mensuel par poste (un dépassement s'affiche en rouge).
  - Un nouveau libellé va dans le PREMIER poste de la liste dont un
    mot-clé apparaît au début d'un mot du libellé ; les flèches ↑ ↓ règlent
    cet ordre. Un libellé associé exactement à un poste l'emporte.
  - Tableau des libellés : changez le poste d'un libellé et toutes ses
    lignes suivent ; l'association est retenue pour la suite.
  - « Vérifier avec les mots-clés » propose de reclasser les anciennes
    lignes ; vous cochez ce que vous acceptez.
Postes par défaut : Foyer, vivres · Loyer, logement · Aides et dons ·
Enfants, école · Santé · Voiture · Téléphone, internet · Transport ·
Repas, boissons · Perso · Autre.


12. COURANT ET EXCEPTIONNEL, PROGRAMMÉES, RELEVÉS, TIERS
--------------------------------------------------------
Événements (Données et réglages › Événements et revenus) : un mariage, un
baptême, des funérailles, un voyage, une mission… regroupe des dépenses ET
des revenus exceptionnels, ce qui donne son bilan net. Ses mots-clés
rattachent les saisies (« hôtel dakar » → Mission à Dakar). Les types de
revenus sont courants (salaire, primes, intérêts) ou ponctuels (mission,
atelier, consultance, jury…). Les vues séparent le courant de
l'exceptionnel ; les soldes des comptes comptent tout.

Revenu courant avec une part ponctuelle : un seul virement qui contient le
salaire ET un rappel ou un bonus (par exemple 800 000 reçus, dont 400 000 de
salaire). Notez une seule opération du montant du virement, type Salaire,
et remplissez « Dont ponctuel » : le montant exceptionnel et son type. Le
solde du compte et le relevé bancaire gardent le virement entier ; le taux
d'épargne et les revenus courants ne comptent que la part habituelle ; la
part ponctuelle va dans l'exceptionnel. Le journal l'affiche (« dont … »)
et l'export Excel la donne dans la colonne « Dont ponctuel ».

Opérations programmées (onglet « Programmées ») : frais de tenue de compte,
abonnements (montant fixe, chaque mois, trimestre…), intérêts d'un compte
épargne (solde × taux). Chaque échéance passée s'annonce par un bandeau
« … à confirmer » : on coche, on corrige la date ou le montant d'après le
relevé, puis « Enregistrer » ; « Ignorer » écarte une échéance non
prélevée. Rien n'est enregistré seul. Le 30 ou le 31 devient le dernier jour
des mois plus courts.

Relevé bancaire (onglet « Relevé bancaire ») : choisissez le PDF ou une
photo du relevé, le compte et la date de départ, puis « Analyser ». Daftar
range chaque ligne : ✓ déjà notée (même montant, date à ±5 jours) ; ✎ à
corriger (montant proche à ±15 %) ; ➕ à ajouter (nature et poste proposés ;
un paiement par carte et sa commission forment une seule ligne) ; ⚠ notée
dans le carnet mais absente du relevé. On coche ce qu'on accepte ;
« Appliquer la sélection » montre un résumé à confirmer, et le solde du
relevé peut être noté sur le compte. Le relevé est lu dans l'appareil et
n'est envoyé nulle part. Un PDF de banque se lit directement ; un PDF scanné
ou une photo passe par une reconnaissance de texte (environ 15 Mo
téléchargés la première fois) : vérifiez alors les montants.

Comptes gérés pour des tiers (type « Compte d'un tiers ») : l'argent que vous
gardez ou gérez pour quelqu'un (un frère qui vous a confié une somme, la
caisse d'une maison familiale…). Renseignez le titulaire, votre nom tel
qu'il apparaît dans ses notes (« ali ») et le libellé de vos versements
(« contribution maison »).
  - Leurs dépenses et entrées ne comptent ni dans vos dépenses, ni dans vos
    revenus, ni dans vos statistiques.
  - Un solde positif appartient au tiers. Un solde négatif est de l'argent
    que vous avez avancé : au choix, « compté comme dette » (il entre dans
    « On vous doit ») ou « en sourdine » (affiché, mais hors de votre
    patrimoine).
  - Votre part (« contribution maison ») reste votre dépense ; le champ
    « Versé au compte de » la fait aussi entrer sur le compte du tiers.
  - Historique d'un tiers : Coller une liste › « Lignes d'un seul compte ».
    « −40 000 savon » = dépense du compte ; « 20 000 prt Halima » = dépôt de
    Halima ; « 50 000 prt Ali » = votre part, rattachée à la dépense déjà
    notée (même montant, à 5 jours près) ou ajoutée en espèces ;
    « ( −244 000 ) » en fin de ligne = solde du compte ce jour-là.


13. TÉLÉPHONE SYNCHRONISÉ AVEC L'ORDINATEUR
-------------------------------------------
Plutôt que la version autonome (chapitre 1), le téléphone peut travailler
sur les données de l'ordinateur, même hors ligne. Les deux sont reliés par
Tailscale (installé et connecté sur les deux, même compte). Sur
l'ordinateur :
    sudo tailscale set --operator=$USER
    tailscale serve --bg 8780
« tailscale status » donne le nom de l'ordinateur en …ts.net. Ouvrez
https://<nom-de-l-ordinateur>.ts.net dans Chrome sur le téléphone, puis ⋮ ›
« Installer l'application ». Pour couper cette adresse :
tailscale serve --https=443 off

  - Saisies, réglages, soldes notés et reclassements se font hors ligne :
    ils sont gardés dans le téléphone et envoyés dès que l'ordinateur est
    joignable. Seul le retour en arrière (« Sauvegarde et retour ») demande
    la liaison.
  - La synchronisation est automatique (ouverture, retour du réseau, toutes
    les 2 minutes) ; le bouton en haut (« ✓ À jour », « 3 en attente »,
    « Hors ligne ») la lance tout de suite. Sans réponse en 20 secondes, il
    passe à « Hors ligne ».
  - Une ligne modifiée des deux côtés : la modification la plus récente
    gagne, et un message le signale. Les heures sont comparées sur
    l'horloge de l'ordinateur : un téléphone mal réglé ne fausse pas le
    résultat. Une ligne refusée (montant nul…) reste dans le téléphone,
    signalée « refusée », à corriger.
  - Réglages : seul ce qui a été changé sur le téléphone est appliqué ; un
    poste ou un compte ajouté sur l'ordinateur entre-temps est gardé. Un
    même élément changé des deux côtés garde la version du téléphone, et un
    message le signale.
  - Un solde noté pour aujourd'hui retient son heure : les opérations du
    jour saisies après lui s'y ajoutent. Une vidange envoyée par le
    téléphone met le repère à jour sur l'ordinateur.
  - Daftar s'ouvre tout de suite depuis la copie gardée dans le téléphone ;
    la version la plus récente est chargée en arrière-plan et un bandeau
    « Une nouvelle version de Daftar est prête » propose « Recharger ».

Les données du téléphone sont dans l'espace privé du site, dans Chrome
(base IndexedDB « appya ») ; la copie de référence reste celle de
l'ordinateur. N'effacez pas les données du site dans Chrome tant que le
bouton n'affiche pas « ✓ À jour » : les saisies en attente seraient perdues.

Autre accès, sans Tailscale, sur le même Wi-Fi seulement : installer avec
« bash installer.sh --reseau » (ou « daftar reseau oui »). « daftar etat »
affiche un lien du type http://192.168.1.20:8780/?cle=k7m2… à ouvrir une
fois sur le téléphone. Ce lien contient une clé : ne le partagez pas ; s'il
a fuité, « daftar reseau nouvelle-cle » en crée une autre. La liaison n'est
pas chiffrée : préférez Tailscale.


14. VOS DONNÉES SUR L'ORDINATEUR, LA COMMANDE daftar
----------------------------------------------------
    ~/Daftar/donnees/carnet.json       opérations, réglages, comptes et biens
    ~/Daftar/donnees/sauvegardes/      une copie automatique par jour (60 gardées)

Copie miroir dans le dossier d'où Daftar a été installé (par exemple un
second disque) : carnet.json est recopié à chaque modification, avec les
sauvegardes. Si ce disque n'est pas monté, la copie est refaite plus tard.
« daftar etat » indique la copie miroir. Si ce dossier est sur le même
disque que ~, gardez aussi une copie ailleurs :
    daftar sauvegarder /media/$USER/MA_CLE

Restaurer une sauvegarde :
    daftar arreter
    cp ~/Daftar/donnees/sauvegardes/carnet-AAAA-MM-JJ.json ~/Daftar/donnees/carnet.json
    daftar demarrer

La commande daftar (« appya » fonctionne aussi) :
    daftar                 ouvre Daftar ; s'il est déjà ouvert dans un onglet, aucun
                          onglet n'est ajouté : l'onglet ouvert se signale
    daftar nouvel-onglet   ouvre quand même un nouvel onglet
    daftar etat            tourne-t-il ? à quelle adresse ? copie miroir ?
    daftar arreter | demarrer | redemarrer
    daftar reseau oui|non|nouvelle-cle   accès d'un téléphone du même Wi-Fi
    daftar sauvegarder     copie datée de carnet.json dans Documents
    daftar journal         messages du serveur (en cas de problème)
    daftar dossier         ouvre ~/Daftar

Un seul onglet : si Daftar est déjà ouvert, son onglet fait clignoter son
titre et, si vous avez autorisé ses notifications, une notification vous y
ramène. Pour un second onglet volontaire : clic droit sur l'icône › « Ouvrir
dans un nouvel onglet », ou daftar nouvel-onglet.

Daftar ne lit que le format de données actuel (version 5).


15. CHANGER D'ORDINATEUR, DÉSINSTALLER
--------------------------------------
Le dossier d'installation contient tout : le programme et, dans donnees/,
la copie miroir à jour de vos données.

Sur l'ancien ordinateur :
  1. Sur le téléphone synchronisé, ouvrez Daftar avec l'ordinateur joignable
     et attendez « ✓ À jour ».
  2. Vérifiez la copie miroir : daftar etat.
  3. Copiez le dossier Daftar entier (clé USB, disque externe…).
  4. Facultatif : bash desinstaller.sh (vos données restent en place).

Sur le nouvel ordinateur (Ubuntu) :
  5. Posez le dossier Daftar là où vous voulez garder la copie miroir, puis :
         cd <dossier Daftar>
         bash installer.sh
     Si ~/Daftar n'existe pas encore, l'installation y reprend les données
     du dossier copié. S'il existe déjà, ses données sont CONSERVÉES ;
     l'installation compare les deux carnets et, si celui du dossier copié
     est plus récent, affiche la commande pour l'adopter.
  6. Téléphone synchronisé : installez Tailscale sur le nouvel ordinateur,
     refaites les deux commandes du chapitre 13, puis ouvrez la nouvelle
     adresse …ts.net sur le téléphone et réinstallez l'application.

Venir du téléphone : copiez le fichier exporté (chapitre 10) en
donnees/carnet.json du dossier Daftar AVANT de lancer bash installer.sh.

Désinstaller :
    bash desinstaller.sh          garde vos données
    bash desinstaller.sh --tout   supprime aussi ~/Daftar (copie finale dans Documents)
Il agit toujours sur l'installation réelle, recopie une dernière fois les
données dans la copie miroir et ne supprime jamais le dossier d'origine.
